About WorkAccyr Recipe Logger

This application is a 100% client-side web app built with semantic HTML5, responsive CSS3, and vanilla JavaScript. It runs seamlessly on static hosting (such as GitHub Pages) with zero backend servers required.

  • Local Authentication: Create accounts and sign in using browser localStorage.
  • Recipe Management: Create, search, categorize, and favorite custom recipes.
  • Meal Planning & Tracking: Organize weekly menus and monitor daily calorie intake.

Data Management

Because all data is stored locally in your browser, clearing your browser cache will erase saved recipes. You can export a JSON backup below.
